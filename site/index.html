03 · Comment ça marche

Cinq étapes, une fois par jour.

legifrance-jorf.ts tourne une fois par jour et enchaîne cinq étapes distinctes :

Étape 1

Recherche

Sur l'API officielle Légifrance (fonds JORF, 12 derniers mois) avec des expressions exactes : « sécurité privée », « activités privées de sécurité », « CNAPS », « livre VI du code de la sécurité intérieure »…

Étape 2

Consultation

Du contenu intégral de chaque nouveau texte : visas, articles, signataires.

Étape 3

Filtrage

Par score de pertinence : un texte est gardé si son titre parle de sécurité privée, s'il cite au moins trois articles du livre VI, ou si les termes métier sont assez présents et assez denses dans le corps. Cela écarte par exemple le décret sur les contrats d'apprentissage qui cite « agent de sécurité » une fois toutes les 20 000 lignes.

Étape 4

Résumé

Via Google Gemini, en file d'attente cadencée pour tenir dans le plan gratuit. Le cache est sauvegardé après chaque résumé, un texte non résumé attend simplement le passage suivant.

Étape 5

Publication

Du flux RSS régénéré depuis le cache. Un texte n'y entre qu'une fois résumé.

Les fichiers de travail sont versionnés dans le dépôt :

FichierRôle
legifrance-jorf.feed.xmlLe flux RSS
legifrance-jorf.cache.jsonLes textes retenus, leur contenu intégral et leur résumé
legifrance-jorf.ignored.jsonLes textes écartés, avec leur titre, pour auditer le filtre
site/Cette page, publiée sur GitHub Pages, avec ses polices et son logo

04 · Faire tourner les flux en local

Trois clés, une commande.

Deno, un compte PISTE et une clé Gemini (le plan gratuit suffit) sont requis. Créer un fichier .env :

LEGIFRANCE_CLIENT_ID=...
LEGIFRANCE_CLIENT_SECRET=...
GEMINI_API_KEY=...

Puis :

deno run --allow-net --allow-env --allow-read --allow-write --env-file=.env legifrance-jorf.ts

Pour tester sans consommer le quota Gemini, l'option --no-gemini lance le scrape et la génération du flux sans les résumés.

Réglages

Tout se pilote par variables d'environnement, aucune n'est obligatoire :

VariableDéfautRôle
GEMINI_MODELSgemini-3.5-flash-lite,gemini-3.6-flashChaîne de modèles. Un modèle en 404 ou à quota épuisé passe la main au suivant
GEMINI_RPM10Requêtes par minute autorisées
GEMINI_TPM250000Jetons par minute autorisés, budget glissant sur 60 s basé sur la consommation réelle
GEMINI_MAX_PER_RUN100Résumés maximum par passage
GEMINI_ENABLEDtruefalse équivaut à --no-gemini
FEED_URLvideURL publique du flux, pour le lien self du RSS
FEED_LINKLégifranceLien du canal RSS

Les termes de recherche, les motifs de pertinence, les exclusions de titres et les seuils sont en tête de legifrance-jorf.ts, commentés.

En automatique

Le workflow .github/workflows/legifrance-jorf.yml lance le script chaque matin à 06:17 UTC, commite les fichiers s'ils ont changé, puis publie site/ et les flux sur GitHub Pages. Il attend trois secrets dans le dépôt : LEGIFRANCE_CLIENT_ID, LEGIFRANCE_CLIENT_SECRET et GEMINI_API_KEY.

Pour activer la publication, une seule manipulation : dans les réglages du dépôt, section Pages, choisir la source « GitHub Actions ». Le premier déploiement se déclenche à la main depuis l'onglet Actions (« Run workflow »), les suivants sont automatiques.

05 · À savoir

Un repère, pas un avis juridique.

Les résumés sont générés par une IA. Ils aident à repérer vite ce qui concerne les agents et les gérants, mais ils ne remplacent pas la lecture du texte et n'ont aucune valeur juridique. Le lien vers le texte intégral est dans chaque entrée.

Les textes proviennent de Légifrance (DILA), réutilisés sous Licence Ouverte 2.0. Rien n'est modifié, seul le résumé est ajouté.
